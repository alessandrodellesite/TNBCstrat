# TNBCstrat

This repository contains the code used to stratify 235 triple-negative breast cancer (TNBC) patients using gene expression, DNA methylation and copy number variation (CNV) data.

Two families of approaches were applied and compared:

- **Single-omic**: NMF run independently on each data layer.
- **Multi-omic**: MOFA, SNF, iClusterPlus and xintNMF.

The resulting models were then compared through a benchmarking framework (concordance, internal validation and bootstrap stability).

## Repository structure

```
├── preprocessing/   # data preprocessing and subsample generation
├── single_omics/    # NMF on each omic layer
├── multiomics/      # multi-omic clustering models
├── benchmarking/    # concordance, internal validation, bootstrap
├── bootstrap/       # bootstrap runs for all models
├── results/         # plots and comparison of clustering results
├── utils/           # helper functions
└── scripts_hpc/     # job scripts and container definitions
```

## Workflow

### 1. Preprocessing (`preprocessing/`)

- **RNA-seq**: `rna_preprocess.R`
- **CNV**: `cnv_preprocess.R`
- **DNA methylation** (three steps):
  1. `methyl_data_merging.R`: merges all available methylation data.
  2. `methyl_preprocess_1.R`: purity adjustment, using the function in `utils/function_correctBetas.R`.
  3. `methyl_preprocess_2.R`: feature selection with the ELMER package.

### 2. Single-omic clustering (`single_omics/`)

Each preprocessed omic layer is independently fed to NMF (`NMF_all_singleomics.R`, `NMF_extract.R`).

### 3. Multi-omic clustering (`multiomics/`)

The omic data are first adapted to the input format required by each method (`Multiomics_preprocessing.R`). Each `Multiomics_*` script then runs the corresponding model (MOFA, SNF, iClusterPlus, xintNMF) on the data.

### 4. Benchmarking (`benchmarking/`)

- **Concordance metrics** between clustering solutions: ARI, NMI, VI (`Benchmarking_concordance_internal.R`).
- **Internal validation metrics**: average silhouette width, Calinski-Harabasz index, Dunn index, connectivity, Davies-Bouldin index (`Benchmarking_concordance_internal.R`).
- **Bootstrapping** of all models (bootstrap/), using the same subsampled cohorts generated by `generate_subsamples.R`.
- **Survival analysis** of all clustering solutions (Benchmarking_survival.R)

### 5. Visualisation (`results/`)

`Results_comparison.R` produces plots for the visual comparison of the clustering results and their association with clinical/metadata variables.

## Containers and job scripts (`scripts_hpc/`)

Analyses were run on an HPC cluster using Singularity images:

- `basilisk_prebuild.sh`: prebuilds the environment required to run MOFA (needed to work around dependency conflicts with basilisk).
- `sub_job.sh`: contains all the R libraries used across the pipeline, except those required by xintNMF.
- `xintnmf_boot.sh`: contains the libraries required by xintNMF.
- `sub_boot.sh`: submission script for the bootstrap analyses.
